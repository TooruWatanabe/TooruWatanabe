## 📦 [Shipping Record Automation Tool](https://github.com/TooruWatanabe/shipping-record-automation-tool)

Developed a production-ready automation tool that extracts shipment records from an internal web-based system, downloads multi-year Excel files, consolidates the data, and generates analytical CSV outputs.

### Highlights

* Selenium Web Automation
* Automated Excel Download
* Pandas ETL Processing
* Windows Executable Deployment
* Reduced processing time from **20 minutes to 3 minutes (85% reduction)**

---

## 📡 [OBD Batch Processing Tool](https://github.com/TooruWatanabe/obd-batch-processing-tool)

Developed a batch-processing tool for OBD telemetry data that integrates Python with an existing Excel VBA workflow.

The application was distributed as a standalone Windows executable and is currently used for daily business operations.

### Highlights

* Automated processing of **400+ telemetry files**
* Excel VBA Integration
* Windows Executable Deployment
* Reduced processing time from **20 hours to 30 minutes (40× improvement)**

## ⚙️ [EPC Parts Extraction Automation Tool](https://github.com/TooruWatanabe/epc-parts-extraction-tool)

Developed a Selenium-based automation tool that extracts maintenance parts using VIN and FIG information from an internal EPC system.

### Highlights

* Selenium Automation
* CSV Batch Processing
* Windows Executable Deployment
* Reduced processing time from **21 minutes to 5 minutes (76% reduction)**
